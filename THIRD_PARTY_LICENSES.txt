## Level 1 SBOM Invariant Verification (Stand: 2026-09-30)

All 10 architectural and runtime governance invariants are confirmed:
- INV-LOCAL-01: 100% Local-First & Zero Egress (zero network telemetry, zero phone-home calls)
- INV-UNPRIV-02: Unprivileged User-Mode Execution (RunAsInvoker non-elevation principle)
- INV-DETERM-03: Deterministic Classification (bit-for-bit identical multi-host audit verdicts)
- INV-IDENT-04: Identifiability Guard (aggregations with >1 varying dimension reject causal claims)
- INV-RACE-05: Write-Guard Race Protection (concurrent runs skip overwrite if disk has superset)
- INV-WINDOW-06: Discrete Window Tokens (deterministic temporal alignment via calendar grid)
- INV-SINGLE-07: One Current Answer Per Window (historical versions preserve themselves via window tokens)
- INV-COVER-08: Coverage Transparency Floor (uninspected paths categorized as unverifiable)
- INV-LOCK-09: Multi-Host & Lock Hardening (immune to cloud-sync conflict files and lock contamination)
- INV-SLA-10: 48h Response, 5-Day Triage SLA (coordinated disclosure via security@open-bricks.org)
